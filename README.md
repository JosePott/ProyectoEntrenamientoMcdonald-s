# Entrenamiento McDonald's — cuestionario interactivo

Proyecto de aprendizaje autodidacta nacido de mi experiencia como entrenador en McDonald's Vitacura. Su objetivo es practicar procedimientos mediante preguntas de opción múltiple y una dinámica de puntos.

## Cómo funciona

1. Se muestra una pregunta con cuatro opciones.
2. La respuesta recibe una indicación visual de acierto o error.
3. Cada respuesta correcta suma 100 puntos.
4. Al finalizar las cinco preguntas, se presenta el porcentaje de aciertos.

El proyecto utiliza HTML, CSS y JavaScript, sin un proceso de compilación.

## Probarlo localmente

1. Clona o descarga este repositorio.
2. Abre `ProyectoMcdonalds/index.html` en un navegador.
3. Responde el cuestionario y revisa el resultado final.

Algunos recursos externos pueden requerir conexión a Internet.

## Estructura

- `ProyectoMcdonalds/index.html`: interfaz del cuestionario.
- `ProyectoMcdonalds/css/styles.css`: estilos.
- `ProyectoMcdonalds/js/scripts.js`: preguntas, evaluación y puntuación.
- `ProyectoMcdonalds/images/`: recursos gráficos.

## Qué permite explorar el código

Manipulación del DOM, manejo de eventos, estado del cuestionario, bloqueo de respuestas múltiples y cálculo del resultado.

## Alcance actual

El banco de preguntas está definido en el código y la puntuación corresponde a la sesión actual. El objetivo es ofrecer una práctica breve e intuitiva.
